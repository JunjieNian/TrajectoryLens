# Version 0.1 archive

These are the initial offline HTML and source ZIP requested for preservation,
plus the exact files withdrawn from the personal website. They are retained as
an editable baseline; the current application lives in `../web/`.

The former personal-site route has been withdrawn. Version 0.1 relied primarily
on supplied exact state identifiers and did not establish enough value for raw
agent logs. Version 0.2 addresses that limitation through native log import,
call/result pairing, exact invocation repeats and automatically extracted
observable process features.

The new raw-log examples in `../examples/` and `../web/demo.js` are synthetic.
The preserved version 0.1 also includes public SliceGraph aggregate kernels,
with their original source URLs and provenance; these are not raw agent logs.
Do not place private session logs in this archive or commit them to the repository.
